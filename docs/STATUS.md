### 可配数字电平与会话统计（−30/−20 已做设备对比）

此前设备对比版本的 `audio=5` 支持 `audio_level_db=-30/-24/-20`，缺省仍 −30 dB；无效值记录一行并回退 −30。启动时一次选择只读系数 1036/2068/3277，缩放与独立提交守卫共用对应幅度上限。保留 mono、半值远离零舍入、10 ms 淡入淡出及 L=R；未加入抖动，未改 TAS 寄存器和上电事务，audio=1–4 与步骤 13–16 不受此参数影响。

单窗非零提交限制为 120 秒且至多 6000 周期，200 次 wake；边界前淡出、8 个成功零块后静音软关断，随后允许重新唤醒。提交路径独立检查时间、周期、LIVE、无 request/reason、L=R、幅度及缓冲区边界，非法非零请求停止。取消累计 60 秒准入，`live_total` 累加真实 LIVE 准入时段（至 mute 请求或最终停止，不包含零尾段），不截断到额度。3 秒静默关断、失败锁存和有界控制线程退出保持原状。

摘要新增 LIVE ring 欠载周期/补零帧数、同一 LIVE 窗口内 HAL 写入最大间隔、源削顶样本数（每通道 abs≥32767）和输出饱和样本数。会话 worker 使用 16 KiB 滚动尾日志；主机模拟 300 秒日志量，实际 loader 追加路径的最后 32 KiB 含 play、asm close 和最终摘要。

三个电平各穷举 65536 个 mono 输入，验证上限内接受、上限+1 拒绝、静音与淡入淡出；120 秒、6000 周期、201 次 wake 拒绝及超过旧 20/60 秒后合法提交通过。300 秒模拟 15000 周期、3 次 wake/mute、checks 2/2、累计 LIVE 298707844 微秒；普通、ASan/UBSan、TSan 与既有回归见 `work/runs/20261112-audio-level-01/RESULTS.md`。上述为该版本的主机验证；随后的 −30/−20 设备对比与尾日志缺陷见下文。


### 电平对比设备结果（2026-11-12）

`54eac28` 的 −30/−20 dB 两轮均在 GPU/触摸/按键/Wi-Fi/蓝牙开启、300 秒会话下完成，分别完整重启；loader returned、无 panic、cleanup complete、ring 守恒、输出饱和 0。−30 dB 为 7 次 wake、checks 6/6、累计 LIVE 116.7 秒、out_peak 1018≤1036；−20 dB 为 6 次 wake、checks 5/5、累计 169.2 秒、单窗最长 63.3 秒、out_peak 3256≤3277。设备已证实选定电平和旧 20/60 秒额度的放宽；默认仍 −30 dB，−24 dB 未单独设备验证。
