# 功能与限制

记录日期：2026-10-27。以下功能状态来自开发项目截至 2026-10-26 的实验记录；尚未使用本仓库从零构建的产物重新进行实机验证。

| 模块 | 已有开发记录 | 仍需解决 |
|---|---|---|
| 启动 | Mi 8 经 UEFI/xnuloader 进入 XNU 8796 与 iOS 16.5 用户空间 | 公开包完整构建与设备配置复现 |
| 显示/GPU | A630/Mesa sysmem 渲染 SpringBoard | 卡顿、功耗、长期稳定性 |
| 输入和外设 | 触摸、音量键、亮度、手电筒、振动和电量有可用记录 | 不能推定所有边界场景稳定 |

| 蜂窝/音频 | 有处理器启动和协议研究 | 不宣称电话、移动数据或完整音频可用 |
