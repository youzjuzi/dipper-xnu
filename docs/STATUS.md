## 当前阻塞与限制

- 完整 XNU `all` 的导出检查和工具生成仍失败；尚无全新 Ubuntu 安装验证。
- 通用设备配置和充电全过程未验收；用户状态持久保存只完成首测（见上表），异常退出会丢上次保存之后的改动。
- 桌面卡顿、功耗及 GPU SMMU/基带退出恢复仍需处理；各轮之间要求完整重启，不能直接连续 rerun。
- 电话、移动数据、完整音频（含蓝牙音频）、摄像头、定位及其他未覆盖硬件不列为可用。
- GPU 初始化表与 APSL 内核组合的分发条件仍未解决，见 [GPU 许可说明](legal/GPU_LICENSE.md)。

## 声音（进行中：诊断短音可听；iOS 输出已验证一次有界会话）

`audio=3` 的有界 ring 消费与 120 秒强制零 DMA 已完成主机验证，功放保持复位，设备尚待验收。

## 降低渲染分辨率（可选）

显式追加 `fbscale=2 fb_dpu=1` 后，系统按 750×1624 渲染，由显示硬件 DPU 放大到面板，处理器只做整块拷贝；SpringBoard 库把 UIKit 的状态栏后备样式换成 iPhone X 的样式，红色占位条消失。设备上已进入桌面，状态栏显示正常，持有人感到明显更流畅；每帧拷贝耗时中位数由处理器放大的 6.5 ms 降到 0.5 ms。**实时壁纸不绘制**（系统查不到 750×1624 @2x 的屏幕类别，壁纸进程什么都不画，窗口是黑底），改由 SpringBoard 库在最上面盖一张静态图（`/redwood/etc/wallpaper.jpg`，没有则用渐变）；设置里换壁纸不会改变它。画面比原来软。设置、信息等应用在降分辨率的启动里出现过闪退；原分辨率下各打开一次没有闪退（样本小），原因未定。默认不启用；Wi-Fi、触摸、按键在该配置下的完整回归和长时间稳定性未验证。参数、前提和限制见[启动教程](install/STARTUP.md#降低渲染分辨率可选不是默认值)，数据见[验证记录](validation/VALIDATION.md#降低渲染分辨率与状态栏2026-11-10)。

音频线程栈压缩已通过主机构建与调用图预算检查，新增压缩随 audio=4 的一次短时设备回归通过；静态 PCM 暂存区沿用已有设备修复。

`audio=4` 已在 GPU/触摸/按键开启、无线关闭的桌面下验证一次 iOS 铃声片段：持有人确认约 3 秒、只响一次、开头结尾无爆音。固定 −30 dB 线性衰减，无 HPF；150 块，输出峰值 269（上限 1036），静音读回 03/01、关断成功、reset 低，6000/6000 周期、守恒与 cleanup 通过，无 panic。仅此一次短窗口；idle/wake、panic 应急、无线并存及长时/热安全未验证。

`audio=5` 已在无线关闭、桌面默认配置下完成单次 120 秒设备验证：7 次 wake/mute，后 6 次只读 Y 校验均为 5d，证实软关断且 reset 保持高时系数保留；warmup 225–591 ms，out_peak 1035，每次静音读回 03/01，6000/6000、守恒与 cleanup complete，无 panic。累计准入上限 60 秒、固定 −30 dB 衰减、无 HPF；该轮累计预算末尾出现过短窗口；后续主机修复见下文。

panic 应急复位已在单独完整重启的受控设备轮次验证：`audio=5 audio_panic_test=1` 首次 LIVE 后约 1 秒触发 panic，缓冲区记录复位拉低标记；持有人确认停声、无爆音。诊断参数默认关闭。钩子不保证早期/嵌套 panic、CPU 停止失败或无 panic 的硬挂死。

上述早期会话与 panic 设备轮次均关闭 Wi-Fi/蓝牙；其证据仅覆盖单次有界会话，无线共存结果见下文。不支持 ADSP 停后再启，长时间与热安全未验收。

`audio=5` 与 Wi-Fi/蓝牙/GPU 共存已完成单次 300 秒设备验证：无线就绪等待 16032 ms，DONE 最大间隔 21.7 ms，最大迟到 1.76 ms（周期 5282），音频持 SMMU 锁最长 1.35 ms，Wi-Fi map 等锁最长 0；6 次 wake/mute、只读系数校验 5/5、out_peak 1007，ring 守恒，cleanup complete，无 panic。无音频对照组的 Wi-Fi 网页与蓝牙耳机连接正常；音频组持有人确认无线正常、无卡顿。

该轮仍为固定 −30 dB、单窗 20 秒、累计 60 秒、20 次 wake 上限；live_total 59990 ms 后 budget exhausted，后续不再出声符合该版额度。持有人在最大音量下反馈“声音不大，有一点破音感”；未定位源削顶、LIVE 欠载或量化误差，不能称音质通过。仅单次 300 秒，不支持 ADSP 停后再启，长期与热安全未验。

会话显式启用共享事务串行化，预留 CB43/SMR8；SMMU 锁仅覆盖映射建立和 detach，DMA 播放期间释放，Wi-Fi 仅允许使用 CB44 且避开 SMR8。ADSP 加载等待 WLFW FW_READY 和有效 CB44 映射，失败或最多 90 秒超时则保持音频关闭。

共存设备版新增 `audio_seconds=1..300`（缺省 120），共存候选使用 300 秒、15000 周期和 `loader_return_after=420`。开始流前检查完整时长及收尾余量，不足则拒绝；累计剩余不足 1 秒时不再 wake，摘要标记 `budget exhausted`。单窗 20 秒、累计 60 秒、20 次 wake、固定 −30 dB 和 ±1036 上限保持不变。最终摘要新增 DONE 最大间隔、最迟成功提交周期/迟到量、音频持锁和 Wi-Fi map 等锁最长时间；本轮已采集上述共存统计，数值见设备结果。

### 可配数字电平与会话统计（主机完成，设备待验证）

`audio=5` 支持 `audio_level_db=-30/-24/-20`，缺省仍 −30 dB；无效值记录一行并回退 −30。启动时一次选择只读系数 1036/2068/3277，缩放与独立提交守卫共用对应幅度上限。保留 mono、半值远离零舍入、10 ms 淡入淡出及 L=R；未加入抖动，未改 TAS 寄存器和上电事务，audio=1–4 与步骤 13–16 不受此参数影响。

单窗非零提交限制为 120 秒且至多 6000 周期，200 次 wake；边界前淡出、8 个成功零块后静音软关断，随后允许重新唤醒。提交路径独立检查时间、周期、LIVE、无 request/reason、L=R、幅度及缓冲区边界，非法非零请求停止。取消累计 60 秒准入，`live_total` 累加真实 LIVE 准入时段（至 mute 请求或最终停止，不包含零尾段），不截断到额度。3 秒静默关断、失败锁存和有界控制线程退出保持原状。

摘要新增 LIVE ring 欠载周期/补零帧数、同一 LIVE 窗口内 HAL 写入最大间隔、源削顶样本数（每通道 abs≥32767）和输出饱和样本数。会话 worker 使用 16 KiB 滚动尾日志；主机模拟 300 秒日志量，实际 loader 追加路径的最后 32 KiB 含 play、asm close 和最终摘要。

三个电平各穷举 65536 个 mono 输入，验证上限内接受、上限+1 拒绝、静音与淡入淡出；120 秒、6000 周期、201 次 wake 拒绝及超过旧 20/60 秒后合法提交通过。300 秒模拟 15000 周期、3 次 wake/mute、checks 2/2、累计 LIVE 298707844 微秒；普通、ASan/UBSan、TSan 与既有回归见 `work/runs/20261112-audio-level-01/RESULTS.md`。新电平的音量、杂音、设备尾日志、长期与热安全仍待设备验证，主机通过不改变此前设备听感结论。
