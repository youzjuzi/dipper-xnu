# dipper-xnu

面向 `dipper`（SDM845）的 XNU 与移动用户空间实验性移植项目。

基于 [HackiOS](https://github.com/oosexgang/hackios-xnu-kernel) 的工作，为 `dipper` 适配启动、显示、触摸、A630 GPU 和 WCN3990 Wi-Fi。目前已有进入 SpringBoard 桌面、GPU 渲染、触摸操作及通过 Wi-Fi 使用 Safari 的实机记录。

项目仍在开发中，尚不适合作为日常使用系统。

## 设备与系统

| 项目 | 配置 |
| --- | --- |
| 设备代号 | `dipper` |
| SoC | SDM845 |
| GPU | A630 |
| Wi-Fi | WCN3990 |
| 内核 | XNU 8796.121.2 |
| 用户空间 | iOS 16.5 |

启动流程：

```text
dipper 启动固件 → edk2-sdm845 UEFI → xnuloader → XNU → iOS 用户空间
```

## 安装方式

当前实机路线需要在设备 UFS 上划出独立的 `darwin` 分区。首次分区会清空 Android 用户数据，系统镜像持久写入该分区；之后通过临时加载 UEFI 启动。它不是无需分区的纯 RAM 运行方案。

具体流程见 **[分区、写入与启动教程](docs/INSTALL.md)**，包含备份、布局核对、分区模板、镜像组合、写入回读及启动步骤。设备参数和用户空间打包仍需补齐并验证，不能直接套用开发设备的分区值。

## 获取源码与构建

本仓库采用 **固定上游版本 + dipper 适配补丁** 的形式组织源码。源码准备脚本获取对应版本的上游项目，再应用本项目的修改。

请按 **[Ubuntu 26.04 构建教程](docs/TUTORIAL.md)** 准备环境、获取源码并构建。教程按步骤说明命令、预期产物和常见问题。

开发主机为 **Ubuntu 26.04.1 LTS（x86_64）**，采用 Linux 构建流程。当前已完成补丁离线回放核对，完整的干净环境构建及启动流程尚未验证；用户空间打包和设备配置的待补步骤也列在教程中。更多实现细节见 [构建说明](docs/BUILD.md)。

仓库不提供系统镜像、专有 SDK、设备固件或设备备份。构建所需的外部材料由使用者自行合法获取。

## 已知问题

- 桌面仍有卡顿，动态调频、功耗和长期稳定性尚待完善。
- 部分系统服务和应用功能不完整，不能将 Safari 可用理解为所有联网功能正常。
- GPU SMMU 和基带的退出恢复仍有问题，实验之间可能需要完整重启设备。
- 存储配置仍来自特定实验布局，不能直接套用到其他设备。本仓库已移除开发设备的分区唯一 GUID，尚不提供通用安装或一键刷机流程。

设备操作前应准备可靠的备份和恢复方案。请先阅读构建指南中的设备配置限制，不要直接使用历史分区参数。
